03 / 客户端与设备

设备不同，选择思路也不同

我们不在这里塞下载地址，因为本页拿不到可靠的官方来源。下面只讲选择思路，具体安装包请以你信任的官方渠道为准。

桌面端

电脑上，先用你系统自带的习惯

Windows 与 macOS 上可选的客户端类型较多，优先选你愿意长期维护、能自行核查来源的那一个。装之前看一眼版本号与发布方，比装完再折腾省事。

桌面端适合长时间在线的场景，也因为屏幕大，更容易看清当前连接状态与用量。

移动端

手机上，把台数算进去

手机和平板通常算作独立设备。如果你的设备数接近当前档位上限，与其反复登出登入，不如直接看高一档。

移动端使用时间零碎，流量消耗往往比预想更快，建议每周粗看一次用量。

路由器 / 家庭场景

一个账号，多个屏幕

把连接放在路由器层面，家里多台设备共用会更省事，但设备台数的统计方式也可能因此变化，具体以你实际看到的为准。

如果家里有电视、游戏主机这类设备，建议先确认它们在不在你的台数预算里。

临时与备用

给自己留一个 Plan B

出差、换网络、临时借用别人的电脑，这些情况都会遇到。提前想好一个备用方式，通常比临时找教程更从容。

无论用哪个客户端，请避免把订阅信息随手转发给他人，这是最基本的一条。

04 / 常见问题

几个被问得最多的问题

双栏并排，左边偏“买之前”，右边偏“买之后”。对号入座就好。

三档套餐，我到底该怎么选？

只看两个数字：每月流量和同时在线设备。基础版适合一个人、设备控制在 3 台以内；旗舰版适合一两个人共用、偶尔玩游戏；团队版面向设备多、需要定制路由的场景。超出这两项再考虑其他差异。

年付一定比月付划算吗？

从页面展示的折算价看，年付确实更低。但划算与否取决于你会不会用满一年。如果你只是短期试试，或者用量不稳定，先按月付走，等确认顺手了再考虑年付，我们不会催你。

流量当月用不完，能留到下个月吗？

本页没有关于流量结转的规则说明，所以我们不能替你承诺可以或不可以。建议在付款前直接向服务方确认这一条，得到明确答复后再决定。

“普通线路节点池”和“IPLC 专线”差别在哪？

按页面展示，基础版使用普通线路节点池，旗舰版包含 IPLC 专线的游戏加速优化，团队版提供 VIP 专属高带宽节点。本页不提供线路数量、延迟或稳定性数据，具体表现请以你的实际使用环境为准。

设备台数怎么算？换设备要重新买吗？

各档位分别标注了 3 台、5 台、20 台的同时在线设备数，指的是同一时间在线的设备数量。是否为“替换登录”还是“新增占用”，本页没有细则，请向服务方核实后再安排你的设备。

你们提供客户端下载链接吗？

本页不提供。我们没有可靠的官方来源可以直接链接，与其给你一个可能过期的地址，不如请你从自己确认可信的官方渠道获取，并核对发布方与版本信息。

团队版的定制路由和客户经理，怎么落地？

这两项属于需要沟通的条目，不在页面上自助完成。建议在订阅团队版之前，先把你的网络结构、设备情况和期望讲清楚，确认可以做到什么程度，再付款。

用起来不顺手，能退吗？

本页没有可依据的退款条款，我们不能凭印象给你一个“可以”或“不可以”。请在下单前找到并读完正式条款，把退费条件、时限和处理方式问明白，这是对自己负责。
